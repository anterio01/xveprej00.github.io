# Kompozice
Stránka se skládá z 5ti vizuálně oddělených sekcí, odkazy v sekci o projektech odkazy vedou na "podstránky", které více rozvádějí danou tématiku
+ ukazují úryvky kódů z projektů a v IMP případě i dodává odkaz na video ukázku, ITW odkaz vede zpět na úvodní stránku.

# CSS techniky
Z CSS se pro dividers využívaly SVG. Časté využívání Flexbox a Grid pro uspořádání obsahu sekcí. Části Carousel a Lightbox mají trochu jiný styl
CSS z důvodu, že se jedná o inspiraci/úpravu/doplnění z Mozilla a W3Schools. Časté využití hover efektů pro zvýraznění karet či odkazů.

# Adresářová struktura
Styly, sub pages, script mají své vlastní složky. Veškeré obrázky se nachází ve složce imgs, která je pak dále rozdělena na podsložky, podle
jejich využití.

# Zdroje + AI
Obrázky čerpány z vlastní galerie. Stránek škol/google images se jménem škol.

Při vytváření projektu se používala hlavně stránka W3Schools a Mozilla jako dokumentace,
AI bylo využito na kontrolu, jestli je správně implementována aria všude, popřípadě
bugy v podobě překlepů jmen, pokud jsem je sám nenašel. Další využití AI byla výpomoc s JS u Lightboxu,
burger menu, Carousel aby mi popřípadě dovysvětlilo určité části z příkladů z W3Schools, Mozilla
a doplnění aria měnění atributu na burger menu.
